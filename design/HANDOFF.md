# Лендинг «Личная CRM» — задание на вёрстку

Статичная одностраничная посадочная. Стек: **Astro** + **Tailwind CSS 4**. Без JS-фреймворков и клиентских скриптов.

Одно целевое действие — перейти в приложение. На странице две одинаковые кнопки «Открыть приложение» (первый экран и финальный блок), обе ведут на один адрес.

## Что в папке

| Файл | Что это |
|---|---|
| `HANDOFF.md` | это задание: структура, токены, адаптив, критерии приёмки |
| `tokens.css` | токены дизайна в формате Tailwind 4 `@theme` — подключить как есть |
| `content/landing-copy.md` | утверждённый текст лендинга, источник истины по копирайту |
| `reference/mobile.html` | эталон мобильной версии (ширина 390 px), открывается в браузере |
| `reference/desktop.html` | эталон десктопной версии (контейнер 1200 px), открывается в браузере |

Эталоны — макеты на инлайн-стилях. Это **референс по виду и размерам**, а не код для копирования: верстать на Tailwind-классах и токенах из `tokens.css`. Если эталон и это задание расходятся — прав эталон по виду, задание по структуре и поведению.

## Настройка проекта

- Astro (последняя стабильная), Tailwind 4 через `@tailwindcss/vite`, `output: 'static'`.
- Шрифт **Manrope** (кириллица, веса 400–800): `@fontsource-variable/manrope`, без внешних запросов к Google Fonts.
- Адрес приложения — в одной константе / env: `PUBLIC_APP_URL` (сейчас неизвестен, поставить `#` и TODO).
- `<html lang="ru">`, `<title>Личная CRM — помните каждого, с кем знакомы</title>`, meta description из подзаголовка первого экрана, `viewport`, favicon — иконка-человечек из шапки.

Предлагаемая структура:

```
src/
  layouts/Base.astro
  pages/index.astro
  components/
    Header.astro        логотип
    CtaButton.astro     кнопка «Открыть приложение» + подпись под ней (prop note)
    Hero.astro          + ContactCard.astro
    Problem.astro       + PhoneContacts.astro, PainItem.astro
    Solution.astro      + StepCard.astro
    Benefits.astro      + BenefitCard.astro
    FinalCta.astro
    Footer.astro
    icons/              инлайн SVG из эталона (stroke, currentColor)
  styles/global.css     @import "tailwindcss"; + tokens.css
```

## Адаптив

Mobile-first. Мобильный макет — база (проверять на 360–430 px), десктопная раскладка включается с `lg` (1024 px). Между ними (`md`) — мобильная раскладка с более широкими полями, без горизонтального скролла.

- Контейнер: `max-w-[1200px] mx-auto`, поля `px-5` на мобильном, `px-6` с `lg`.
- Вертикальные отступы секций: 56 px мобильный → 104 px десктоп (финальный блок 120 сверху / 96 снизу).

| Элемент | Мобильный | Десктоп (`lg`) |
|---|---|---|
| H1 | 40/1.08, 800, tracking −0.035em | до 68/1.04, tracking −0.04em (`clamp(40px,5vw,68px)`) |
| H2 секций | 34/1.1, 800, −0.03em | до 52/1.08 (`clamp(34px,3.6vw,52px)`) |
| H2 финала | 36/1.08 | до 56/1.06 |
| Лид-абзацы | 17/1.5 | 20/1.5, max-width 520–640 px |
| H3 шагов | 20 | 24 |
| H3 выгод | 18 | 22 |
| Текст карточек | 15–16 | 17–18 |
| Подписи | 14 | 15 |
| Кнопка | высота 58, на всю ширину, 17/700 | высота 60, по содержимому, px 40, 18/700 |

## Блоки по порядку

Тексты брать дословно из `content/landing-copy.md`.

### Шапка
Логотип: иконка-человечек (stroke, цвет accent) + «Личная CRM», 800. Мобильный — по центру, десктоп — слева. Других ссылок нет.

### 1. Первый экран
- Мобильный: всё по центру, колонкой: плашка-надпись (белый pill) → H1 → подзаголовок → кнопка + подпись → карточка контакта.
- Десктоп: две колонки. Слева текст и кнопка (выравнивание по левому краю), справа карточка (max-width 480).
- **ContactCard**: белая карточка radius 24/28 с тенью, за ней сверху выглядывает подложка `lavender-200` (вторая «карточка в стопке»). Внутри: аватар-инициалы «АП» (coral-100 / coral-700), имя, роль, два чипа («подруга Маши», «конференция, Казань»), сетка 2×1 «Телефон / Почта», жёлтая заметка с датой «12 окт.». Телефон и почта в макете вымышлены — оставить как есть или заменить на очевидно ненастоящие.

### 2. Проблема
Белая секция, верхние углы скруглены (32 мобильный / 48 десктоп).
- Заголовок «Знакомо?» и текст — по центру.
- **PhoneContacts**: блок `surface-soft` с подписью «Контакты в телефоне» и пятью строками (аватар-буква + имя). У «Олег ???» аватар и «???» — коралловые.
- Три боли: карточки `coral-50` с коралловой иконкой в квадрате (вопрос, облачко чата, лупа).
- Десктоп: список контактов слева, боли справа (flex ~1 : 1.4).

### 3. Решение
- Заголовок и текст по центру.
- Три **StepCard**: белые, radius 24/28, мягкая тень, круг с номером (accent, белая цифра), H3, текст. Во втором шаге — имитация поиска: «Ан» тёмным, «на Петрова» приглушённым.
- Мобильный — колонкой, десктоп — тремя в ряд.
- Плашка `lavender-200` с иконкой облака: «Контакты хранятся на сервере…».

### 4. Выгоды
Белая подложка radius 32/48 (на мобильном с отступом 8 px от краёв экрана).
- Заголовок «Что изменится», подзаголовок цвета accent, 600.
- Четыре **BenefitCard** (`surface-soft`): иконка accent + H3 в строку, ниже текст. Мобильный — колонкой, десктоп — сетка 2×2.

### 5. Призыв к действию
По центру: стопка из трёх кругов (АП, О, «+» на accent) с наложением −12/−14 px и обводкой цвета фона, H2, текст, кнопка, подпись «Работает в браузере, устанавливать ничего не нужно».

### Подвал
Линия `lavender-200` сверху, логотип маленький. Мобильный — по центру, десктоп — слева.

## Кнопка «Открыть приложение»
Один компонент на обе позиции. `<a href={PUBLIC_APP_URL}>`, фон accent, белый текст, radius 18, тень `shadow-cta`. Hover — `accent-hover`, focus-visible — кольцо 3 px accent со смещением 3 px. Подпись под кнопкой — prop.

## Доступность
- Семантика: `header`, `main`, `section` с `aria-labelledby` на свой H2, `footer`; один H1.
- Декоративные SVG — `aria-hidden="true"`; иллюстрации (карточка контакта, список контактов) — `aria-hidden` или `role="img"` с коротким `aria-label`, чтобы скринридер не читал вымышленные данные как контент.
- Контраст текста ≥ 4.5:1 — цвета в токенах подобраны под это, не осветлять серые.
- Цели касания ≥ 44 px.
- `prefers-reduced-motion` — анимаций нет, не добавлять.

## Критерии приёмки
1. `npm run build` собирает статичный `dist/` без ошибок и без клиентского JS.
2. На 390 px страница визуально совпадает с `reference/mobile.html`, на 1440 px — с `reference/desktop.html` (шрифты, цвета, отступы, порядок блоков).
3. На 360, 768, 1024, 1280 px нет горизонтального скролла и обрезанного текста.
4. Тексты совпадают с `content/landing-copy.md` дословно.
5. Обе кнопки ведут на `PUBLIC_APP_URL`.
6. Lighthouse: Accessibility ≥ 95, Performance ≥ 95 на мобильном.
