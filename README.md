# Лендинг «Личная CRM»

Одна страница, одно целевое действие — перейти в приложение. Статичная страница на Astro и Tailwind CSS 4: без сервера и базы.

## Как запустить

Нужно установить Node.js 24 и pnpm.

1. Установите зависимости:

   ```
   pnpm install
   ```

2. Запустите страницу в режиме разработки (обновляется сама при изменении файлов):

   ```
   pnpm dev
   ```

3. Откройте в браузере http://localhost:4321

Остановить: закрыть окно, в котором запущено, или нажать Ctrl+C.

### Собранная версия, как на сервере

- `pnpm build` — собрать страницу в папку `dist/`
- `pnpm preview` — открыть собранную версию на http://localhost:4321

### Посмотреть с телефона

Телефон и компьютер должны быть в одной сети Wi-Fi.

1. Запустите `pnpm dev --host`
2. В выводе будет строка `Network` с адресом вида `http://192.168.x.x:4321` — откройте его на телефоне.

## Структура страницы — золотой стандарт

| Блок | Файл |
| --- | --- |
| 1. Первый экран | `src/components/Hero.astro` |
| 2. Проблема | `src/components/Problem.astro` |
| 3. Решение | `src/components/Solution.astro` |

Полный текст страницы одним списком — `landing-copy.md`.

## Где что менять

- Адрес приложения, куда ведут все кнопки, — `src/config.ts` (сейчас `https://app.lyna.tech`)
- Кнопка «Открыть приложение» с подписью под ней одна на всю страницу — `src/components/CtaButton.astro`
- Цвета, шрифты, размеры текста и отступы — только в `src/styles/tokens.css`
- Шрифт Manrope (лицензия SIL Open Font License) лежит в `src/assets/fonts` и подключён в `astro.config.mjs`: страница не обращается к сторонним сервисам

## Макет

Папка `design/`: задание на вёрстку — `HANDOFF.md`, эталоны вида — `reference/mobile.html` и `reference/desktop.html`, токены от дизайнера — `tokens.css`, тексты — `content/landing-copy.md`.

## Как выкатить

Лендинг работает на сервере: https://lyna.tech. Выкатка автоматическая.

### Выкатить новую версию

1. Закоммитьте изменения и сделайте push в ветку `main`.
2. Через минуту-две новая версия на сервере. Ход выкатки виден во вкладке Actions: https://github.com/LubNatalia/personal-crm-landing/actions (зелёная галочка — выкатилось, красный крестик — упало).
3. Проверить: откройте https://lyna.tech — там новая версия.

### Как это устроено

1. GitHub Actions (`.github/workflows/deploy.yml`) собирает страницу в папку `dist/`. На сервере ничего не собирается.
2. Загружает `dist/` на сервер в `/var/www/lyna.tech` через `rsync --delete`: новые файлы добавляются, изменённые заменяются, лишние удаляются.
3. nginx отдаёт эту папку на https://lyna.tech.
4. Проверка: главная отвечает 200 и отдаёт именно то, что только что собрано. Иначе выкатка красная.

Отката нет: если что-то сломалось — исправляем и выкатываем новую версию.

### Ключ выкатки

В GitHub (Settings → Secrets and variables → Actions): секрет `DEPLOY_SSH_KEY` и переменные `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_KNOWN_HOSTS`. На сервере этот ключ может только загружать файлы в `/var/www/lyna.tech` — ни команд, ни других папок.
